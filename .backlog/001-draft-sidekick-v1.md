# Build Draft Sidekick v1

Build Draft Sidekick v1 per the approved PRD at `prd/draft-sidekick/prd.md` ("let's build"). A local web app that attaches to a live Sleeper draft, keeps the board synced automatically, and gives need-aware, opponent-aware pick recommendations from a fresh FantasyPros ECR snapshot — so the drafter never hand-marks a pick again and feels fully informed on every pick. Validation is live Sleeper mock drafts (PRD §14).
